WEB • BUSINESS PLATFORM

Hind Pharma Management Platform.

A practical multi-tenant pharmacy management platform built around real business workflows, including shop administration, medical and product management, order processing, employee work and daily calling.

View GitHub Repository ↗Open Live Demo ↗View Other Projects

Multi-Tenant

Shop identity is isolated by tenant, with separate users, medicals, products, orders and calling data for each business.

Business Workflow

Admin, Manager and Employee flows cover daily operations from medical selection and ordering to employee calling work.

HTG Control

An HTG Super Admin layer manages business units and business Admin accounts separately from shop-level users.

CORE WORKFLOWS

Designed around real pharmacy operations.

Order Flow

Home → Medical List → Medical → Product List → Products → Final Order → Submit Order.

Daily Calling

Today's medicals, contact details, call action and automatic call-event recording with activity safeguards.

Administration

Business Admin manages the tenant while Managers and Employees work inside clearly separated operational flows.

ARCHITECTURE

Simple stack with clear separation.

The project uses a web frontend with a FastAPI backend and SQLite as the persistent database. Tenant-aware data separation is built into the application model.

ENGINEERING FOCUS

Built for a real business, not just a demo.

Role Hierarchy

HTG Super Admin → Business Admin → Manager → Employee.

Data Isolation

Tenant and admin identifiers keep operational records associated with the correct business.

Production Direction

GitHub Pages provides the current browser testing experience; the final production deployment connects the frontend to the persistent backend and payment gateway.
