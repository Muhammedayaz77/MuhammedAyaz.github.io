OPEN SOURCE • SWIFT / iOS

Reusable Swift Developer Toolkit.

A practical collection of reusable Swift extensions for Foundation, UIKit and SwiftUI, designed to reduce repeated boilerplate and provide common functionality that can move from one iOS project to another.

View GitHub Repository ↗ View Other Projects

Foundation

Reusable helpers for collections, strings, dates, URLs, data, persistence and other common Foundation types.

UIKit

Everyday extensions for views, controls, images, colors, tables, collections, device information and view controllers.

SwiftUI

Modern extensions for View, Color, Image and Binding to support clean and reusable SwiftUI code.

WHY I BUILT IT

Write once. Reuse across projects.

The goal is not to collect methods just to increase the number of extensions. The focus is on small, understandable pieces of functionality that are useful across different iOS applications.

ENGINEERING APPROACH

Simple structure, consistent quality.

Extension-first

Functionality is added directly to existing Swift and Apple framework types instead of creating unnecessary utility wrappers.

Organized

Foundation, UIKit and SwiftUI are separated so the toolkit can grow without becoming difficult to navigate.

Consistent

Swift formatting is enforced with a shared configuration and GitHub Actions checks.

EXAMPLE

Readable APIs for everyday work.

let name = "Hind Tech Group"
let length = name.getLength()

let data = try user.toJSONData()
let decodedUser = try data.decoded(as: User.self)

let view = UIView()
view.setSize(width: 100, height: 100)
FUTURE ROADMAP

Built to grow into a stronger developer package.

Future iterations can add focused high-value extensions, unit tests, Swift Package Manager support, more usage examples and expanded API documentation.
